EF Core installation
  1. Install extension Nuget Gallery (for VS Code).
    - For SQLite:
       MS.EntityFrameworkCore.Design  
       MS.EntityFrameworkCore.SQLite
    - For MSSQL:
       - For SQLite:
       MS.EntityFrameworkCore.Design
       MS.EntityFrameworkCore.SqlServer

    ** Design is for Db migration

  2. Create a model/entity table(s)  

  3. Setup a connection string in appsettings.json or appsettings.Development.json

  4. Add the DbContext service in Program.cs for your connection string created in step 3

  5. Migrate and update ur database.

      for VS Code, using the 'dotnet-ef' command in Terminal
        $ dotnet tool install --global dotnet-ef --version 10.0.5

      Stop the server (if running)         .

      run:
      $ dotnet ef migrations add InitialCreate -o Data/Migrations
      $ dotnet ef database update  
      This will create a new database called Restore.db

  To drop a database created
  $ dotnet ef database drop 


Specify your DbContext name
 dotnet ef migrations add MigrationName --context YourDbContextName
 dotnet ef database update --context YourDbContextName
