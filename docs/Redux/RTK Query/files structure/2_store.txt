  useSelector   
    The useSelector hook extracts data from the Redux store state for use in functional React components. 
    
    While useSelector is imported from the react-redux library rather than the Redux Toolkit core package, it is the standard, primary way to read slice states inside your layout components.

    Subscription mechanism: The hook monitors the store and executes your selector whenever an action is dispatched.

    Reference equality: It runs a strict reference check (===) between the old and new return values. Component re-renders only occur if the value changes.

    Object pitfall: Returning a new object inline (e.g., useSelector(state => ({ a: state.a, b: state.b }))) breaks reference equality. This forces a re-render on every dispatch, even if data didn't change.
