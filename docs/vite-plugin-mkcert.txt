vite-plugin-mkcert plugin

  vite-plugin-mkcert is a Vite plugin that automatically generates locally-trusted SSL/TLS certificates using mkcert to enable a zero-config HTTPS development server. It eliminates browser security warnings and ensures your local environment mirrors production requirements.


  To use the plugin, your environment must be running Node.js >= 22.19.0

  $ npm install vite-plugin-mkcert -D
 
  Configure your vite.config.js or vite.config.ts:
  
  import mkcert from 'vite-plugin-mkcert'

  export default defineConfig({
    server: {
      https: true // Instructs Vite to run in HTTPS mode
    },
    plugins: [
      mkcert() // Automatically provisions and updates your local certificates
    ]
  })
